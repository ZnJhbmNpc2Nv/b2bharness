# ФИНАЛЬНЫЙ ОТЧЕТ: B2B-Harness & UI Dashboard

## 1. Обзор системы
Реализован комплексный пайплайн для SDD (Specification Driven Development). Система автоматизирует жизненный цикл разработки модуля от Discovery до Post-SDD, обеспечивая экспертный контроль и безопасность на каждом этапе.

## 2. Итоги разработки
- **Ядро (Harness)**: Статус-машина (`src/engine/pipeline.py`), оркестратор API (`src/api/main.py`), система логирования и безопасности (SAST-сканер).
- **Пайплайн**: Реализованы стадии `PRE-SDD`, `INTENT`, `SPEC`, `PLAN`, `DEV`, `POST_SDD`. Управление осуществляется через `data/approval.json` (Human-in-the-loop).
- **Интерфейс (Dashboard)**: React+Vite приложение для визуализации статуса пайплайна и безопасного управления конфигурацией (API Keys).
- **Безопасность**:
    - Интеграция SAST (проверка на опасные функции).
    - Изоляция окружения (`pydantic-settings`, `.env`).
    - Ограничение ФС (запрет выхода за пределы `root_path`).

## 3. Инструкция по запуску
1. **Бэкенд**:
   ```bash
   cd D:\b2bharness\projects\web_ui_dashboard
   python -m uvicorn src.main:app --port 8000 --reload
   ```
2. **Фронтенд**:
   ```bash
   cd D:\b2bharness\frontend
   npm install
   npm run dev
   ```

## 4. Как подключить агента-кодера
Для продолжения разработки агент должен:
- Иметь доступ к структуре `intent.md` -> `spec.md` -> `plan.md`.
- Следовать логике переходов, подтверждаемых через API `/pipeline/advance`.
- Фиксировать все изменения в `dev_log.md` с привязкой к ID требований из `spec.md`.
