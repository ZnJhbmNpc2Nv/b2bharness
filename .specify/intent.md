# SDD-INTENT: B2B-Harness Pipeline System

## Intent (Зачем и границы)
Система предназначена для нормализации процессов агентной разработки (vibe-coding) внутри B2B-контура. Цель — обеспечить единый стандарт качества, архитектуры и безопасности при создании переиспользуемых программных модулей.
- Границы: Система управляет жизненным циклом SDD-артефактов, не вмешиваясь в логику самих разрабатываемых модулей (модули — черные ящики с интерфейсом Tools/MCP).

## Spec (Валидация)
- Система должна гарантировать прохождение всех стадий: PRE-SDD, INTENT, SPEC, PLAN, DEV, POST-SDD, A/B-TEST.
- Каждое изменение в дистрибутиве модуля должно иметь трассировку до spec.md.
- Валидация: наличие "человека в цикле" (Expert Review) перед переходом между стадиями.

## Plan (Реализация)
- Использовать Python 3.12 + FastAPI + SQLite для оркестрации.
- Реализовать статус-машину, управляющую состоянием каждого артефакта.
- Внедрить механизм "автоматизированной компрессии" (Intent -> Spec -> Plan) с возможностью эскалации на человека.
