# SDD-SPEC: Specification

## 1. Безопасная разработка
- Использование SAST-анализа на этапе DEV.
- Соответствие OWASP ASVS L2.
- Запрет на хранение секретов в коде (использование .env).

## 2. Доменные требования (Web/GenAI)
- Модули должны быть упакованы как независимые сервисы с API/MCP интерфейсом.
- ORM: SQLite (с WAL-режимом для поддержки конкурентного доступа).
- GenAI: поддержка GigaCode SDK.

## 3. Критерии приёмки
- Успешное прохождение всех этапов пайплайна (PRE-SDD -> A/B TEST).
- Наличие файлов dev_log.md и test_log.md для каждого релиза.
- 100% покрытие базовых функциональных сценариев unit-тестами.

## 4. Рекомендации по тестированию
- Использование pytest с автоматической генерацией моков.
- Обязательный A/B тест между референсным кодом и новой версией модуля.
