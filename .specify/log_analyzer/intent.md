# Intent: Log Analyzer MCP

Цель: Создать инструмент, который парсит текстовые файлы логов и выявляет ошибки (ERROR/CRITICAL).
Почему: Ускорение диагностики B2B-инструментов.
Границы: Только парсинг и агрегация статистики. Без отправки данных во внешний мир.
