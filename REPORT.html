Б. Комплексные / масштабные задачи: Выявленное ограничение и решение

💡 Инженерный инсайт: При передаче сверхмассивных спецификаций (250+ строк единым блоком) кодогенераторы могут опускать низкоприоритетные edge cases из-за насыщения attention window.

Принятый архитектурный стандарт: Применение паттерна Spec Slicing (декомпозиция спецификаций). Крупная задача автоматически делится Spec Architect на 2–3 независимых подзадачи (sub-specs), каждая из которых проходит 7-шаговый цикл изолированно с детерминированным 100% результатом.

4. Подсистема безопасности и изоляции ресурсов

  • ContextIntegrityGuard: Блокировка попыток Path Traversal, экранирование шелл-инъекций и детекция расхождения SHA-256 хэша спецификации.
  • Multi-Model Swarm Router: Пул моделей (Claude Opus 5.5, Sonnet 5, Gemini 3.7, Qwen 3.8) с авто-переключением (Failover) при исчерпании квот или задержках.
  • Ephemeral Token Manager: Временные токены для коллег с жестким сроком жизни (48 часов), привязанные строго к эндпоинтам Harness.
