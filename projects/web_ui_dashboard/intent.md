# SDD-INTENT: UI Dashboard Intent

## Intent (Зачем и границы)
- **Зачем**: Визуализировать состояние SDD-пайплайна, дать эксперту удобный инструмент для Approve/Advance и централизовать управление конфигурацией (API Keys).
- **Границы**: Dashboard работает как "тонкий" клиент к FastAPI-бэкенду. Не содержит бизнес-логики самих модулей.

## Spec (Валидация)
- Авторизация: Dashboard должен требовать аутентификацию (на первом этапе — простая токенизация или проверка IP).
- Безопасность: API-ключи передаются по POST и сохраняются в защищенное хранилище (env-file).

## Plan (Реализация)
- Внедрить `pydantic-settings` для управления ключами на бэкенде.
- Реализовать API-эндпоинты для: получения состояния (`/status`), управления (`/approve`, `/advance`), сохранения ключей (`/config/keys`).
- Frontend: React-приложение с использованием `shadcn/ui` (или базовый React для скорости).
