# SDD-PRE: Discovery - UI Dashboard

## Суть проекта
Разработка веб-интерфейса (React/Vite) для визуализации статуса пайплайна разработки и управления ключами доступа (API Keys).

## Функционал:
1. Визуализация текущего статуса пайплайна (какая стадия, одобрено ли экспертом).
2. Форма для ввода и безопасного сохранения API-ключей.
3. Интеграция с FastAPI-бэкендом (отображение dev_log.md, dev_log.json).
4. Управление: кнопки "Approve", "Advance Pipeline".

## Основные ограничения и риски:
- **Безопасность**: API-ключи должны передаваться только через HTTPS и храниться на бэкенде в зашифрованном виде (или .env). UI не должен кэшировать ключи в браузере.
- **Производительность**: Минимизация запросов к API через WebSockets или короткий polling.
