# SDD-SPEC: UI Dashboard Specification

## 1. Безопасность и хранение ключей
- **Хранение**: API-ключи хранятся в `.env` файле на стороне сервера. Запрещено передавать их в логи или клиентские ответы.
- **Аутентификация**: Использование Bearer-токена для всех API-запросов от UI к бэкенду.
- **SAST**: Проверка на отсутствие утечек ключей (hardcoded secrets) в репозитории.

## 2. Доменные требования (Web/React)
- **Frontend**: React + Vite, коммуникация через `axios` или `fetch`.
- **Backend**: FastAPI-эндпоинты:
    - `GET /status`: Возвращает текущую стадию и статус одобрения.
    - `POST /config/keys`: Принимает JSON с ключами, сохраняет в `.env`.
    - `POST /pipeline/approve`: Выставляет `approved=true`.

## 3. Критерии приёмки
- Успешная передача API-ключа из UI в `.env` на бэкенде.
- Корректное обновление статуса на UI при нажатии кнопки "Advance".
- Визуальное подтверждение текущего этапа (PRE-SDD -> POST-SDD).

## 4. Рекомендации по тестированию
- Интеграционный тест: UI -> API -> .env (проверка существования файла).
- Проверка того, что `.env` не доступен через HTTP-запросы.
