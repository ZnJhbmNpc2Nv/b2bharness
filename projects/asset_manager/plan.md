# SDD-PLAN: Asset Manager Development Plan

## Трассировка блоков:

| ID Блока | Описание | Связь со SPEC |
| :--- | :--- | :--- |
| **B1_SCAN** | Файловый сканер с фильтрацией путей | Spec 1.1, 1.2 |
| **B2_HASH** | Модуль хеширования (SHA-256, 64KB) | Spec 2.1, 2.3 |
| **B3_DB** | SQLite хранилище метаданных | Spec 2.2 |
| **B4_REP** | Генератор отчетов о дубликатах | Spec 3.3 |

## План разработки (SDD-DEV):
1. **Этап 1 (Сканер)**: Реализация `AssetScanner` с проверкой путей (блэклист).
2. **Этап 2 (Хеширование)**: Реализация `HashService` с чанковым чтением.
3. **Этап 3 (Хранилище)**: Инициализация БД и реализация DAO для `Asset`.
4. **Этап 4 (Отчеты)**: Реализация логики поиска дубликатов и генерация JSON.

*(Напоминание: ручное редактирование этого файла запрещено, генерация автоматизирована).*
