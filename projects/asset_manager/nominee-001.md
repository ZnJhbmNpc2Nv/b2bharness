# SDD-NOMINEE: Safe FS Patterns

## Формализованные практики
- Использование `pathlib.Path.resolve()` для предотвращения Path Traversal атак.
- Обязательное наличие `root_path` для всех операций с ФС.
- Использование `with open(...)` с чанковым чтением для файлов любого размера.
- Интеграция SAST на этапе `DEV` (сканирование через `ast` — стандарт для "тонких" модулей).
