# SDD-INTENT: Asset Manager Intent

## Intent (Зачем и границы)
- **Зачем**: Обеспечить централизованный контроль за дубликатами активов в B2B-проектах, сократить затраты на хранение и избежать конфликтов версий.
- **Границы**: Инструмент работает только с локальными ФС (чтение), не имеет доступа к облакам или удаленным серверам в текущем скоупе.

## Spec (Валидация)
- Чтение файлов блоками (64KB).
- Исключение системных путей через список запрещенных паттернов.
- Хеширование только через SHA-256.

## Plan (Реализация)
- Стадия INTENT завершена после утверждения экспертом границ.
- Следующая стадия: генерация `spec.md` (автоматизированная).
- Внедрить Unit-тесты для хеширования чанками (проверка на фрагментацию памяти).
