# SDD-PRE: Discovery - Asset Manager

## Суть проекта
Разработка MCP-инструмента для автоматического индексирования локальных активов (файлов).

## Функционал:
1. Сканирование указанной директории.
2. Вычисление хеш-суммы (SHA-256) для каждого файла.
3. Хранение метаданных (имя, путь, хеш, время модификации) в SQLite.
4. Поиск и отчет о дубликатах (файлы с одинаковым хешем).

## Основные сущности:
- `Asset` (файл)
- `ScanResult` (результат операции)
- `DuplicateReport` (отчет)

## Основные ограничения и риски:
- **Безопасность доступа**: Сканирование ограничено только указанным `root_path`. Запрет на доступ к системным директориям (например, `C:\\Windows`, `C:\\Program Files`, `/etc`, `/usr` и т.д.).
- **Производительность**: Чтение файлов для хеширования должно производиться чанками (блоками) по 64KB для минимизации потребления памяти (обработка больших файлов).
