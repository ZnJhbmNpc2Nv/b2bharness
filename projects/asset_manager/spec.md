# SDD-SPEC: Asset Manager Specification

## 1. Безопасная разработка (SAST & Access)
- **Изоляция ФС**: Доступ к файловой системе строго ограничен параметром `root_path`. Запрещено использование `os.path.abspath` для выхода за пределы этой директории.
- **Блэклист**: Системные директории (C:\Windows, /etc, и т.д.) исключаются из сканирования на уровне ядра модуля.
- **SAST**: Использование `ast` для проверки отсутствия опасных вызовов (`eval`, `exec`, `subprocess`) перед любым запуском.

## 2. Доменные требования
- **Хеширование**: Алгоритм SHA-256. Реализация через `hashlib` с использованием `update()` для чтения чанками по 64KB.
- **Хранилище**: SQLite с включенным WAL-режимом.
- **Производительность**: Модуль не должен потреблять более 100MB RAM при обработке файлов любого размера.

## 3. Критерии приёмки
- 100% покрытие unit-тестами для модуля хеширования (проверка корректности хеша на разных размерах файлов).
- Тест-кейс на попытку выхода за пределы `root_path` (должен завершиться ошибкой доступа).
- Генерация `DuplicateReport` в формате JSON.

## 4. Рекомендации по тестированию
- Использовать `pytest` для имитации ФС.
- Включить функциональные тесты на генерацию дубликатов с заранее подготовленным набором файлов.
